# masami

A high density multi-layered packet parsing system built across multiple coding languages. This toolkit links low-level link layer memory traps directly into scalable concurrent visualization frameworks.

## Deep Architectural System Mapping

- **manifest**: Explicit multi language routing schemas mapping exact layout sizes.
- **sniffer**: Low level raw network socket core intercepting link layer memory blocks.
- **processor**: Go runtime tracking tool splitting transaction metrics into parallel channels.
- **analyzer**: Python behavioral script processing unencrypted packet text payloads.
- **dashboard**: Bash orchestrator constructing screen layout structures on the fly.
- **blacklist**: System lookup rules mapping malicious network locations.
- **storage**: Disk synchronization rules forcing local metadata caching parameters.

## Native Compilation and Hardware Orchestration

Execute this sequential script layer inside your terminal window to initialize the full operational workspace:

g++ -O3 -std=c++17 sniffer.cpp -o sniffer -lpcap
go build -o processor processor.go
chmod +x dashboard
chmod +x analyzer.py

sudo ./sniffer | ./processor
